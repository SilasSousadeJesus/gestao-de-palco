# `stage-screen` - record

- A rota `/palco?evento=<id>` renderiza o monitor de palco sem controles administrativos.
- O componente compartilhado mostra bloco, timer gigante, pausa e tempo excedido.
- `stage-timing.ts` centraliza o calculo e possui teste para tempo positivo, pausado e negativo.
- `npm run lint`, `npm run typecheck`, `npm run test:db` e `npm run build` passaram.
- Consultados e atualizados: `docs/PRODUCT.md`, `docs/ROADMAP.md`, `docs/PROJECT-STATE.md` e `.sdd/MAP.md`.
